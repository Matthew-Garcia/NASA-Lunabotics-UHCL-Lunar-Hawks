# Mechanical CAD and meshes

All mechanical assets are kept directly in this directory. It includes the five preserved project STLs, the reference-derived full-rover OpenSCAD/STL reconstruction, excavator and bucket parts, electronics enclosures, goal-post geometry, wheel variants and preview images.

- See [`WHEEL.md`](WHEEL.md) for the 248 mm Bambu-compatible wheel and 300 mm laboratory wheel variants.
- See [`AUTONOMY_CAD.md`](AUTONOMY_CAD.md) for the earlier autonomy-development models.

Native STEP/SolidWorks sources for the complete rover were not supplied. Before printing or manufacturing, confirm units, scale, hub and fastener interfaces, tolerances, materials, load suitability, authorship and third-party licensing. Generated geometry is reference/development CAD, not a fabrication-authoritative release.
