# CAD notes

`grouser_wheel_12_short.scad` is the main requested wheel model. It preserves the documented **304.8 mm diameter, 100 mm width and 12 evenly spaced grousers**, while using a 22 mm radial grouser projection in the parametric source (half of the 44 mm baseline used in this generated model).

These files are simulation/reference geometry, not production-release mechanical drawings. The wheel should be dimension-checked against the rover's actual hub/bolt pattern before printing.
